# carousel-thematic

Custom **carousel** block. Purpose: tabbed-thematic-product-carousel.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One block instance per tab. Row 1 = thematic panel: cell 1 = Gift Zone image, cell 2 = tab label as heading ("Gift Zone") + "Shop All" link. Rows 2..13 = products: cell 1 = product image, cell 2 = brand (bold) + title (linked to PDP), price, was-price (strikethrough) + savings, rating/review count, social-proof text, "Add to Cart" link. Consecutive instances in the section form the tab bar ("Gift Zone", "Top Deals"); a single instance shows its heading as the only tab. When the thematic image carries its own copy, the whole image links to the "Shop All" URL and the heading/link text stay available to screen readers only.
