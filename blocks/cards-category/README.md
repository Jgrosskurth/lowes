# cards-category

Custom **cards** block. Purpose: popular-category-banners.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per banner (4 rows): cell 1 = image; cell 2 = link (category label as link text).. Optional mobile art: a second image in the same image cell is the mobile variant, shown below 576px (desktop image above); both render as one picture, so only one image downloads.
