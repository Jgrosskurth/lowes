# carousel-hero

Custom **carousel** block. Purpose: homepage-hero-rotator.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per slide (5 rows): cell 1 = linked hero image; cell 2 (optional) = "Get Details" link/text for the offer-details disclosure.. Optional mobile art: a second image in the same image cell is the mobile variant, shown below 576px (desktop image above); both render as one picture, so only one image downloads.
